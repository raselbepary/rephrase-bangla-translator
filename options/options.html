Rephrase & Bangla Translator

AI provider

Used for rephrasing, reply drafting, and as a backup for translation when the free Google Translate service is rate-limited or down. Any OpenAI-compatible server works — OpenAI, DeepSeek, Grok, Ollama, LM Studio, llama.cpp, vLLM…

get a key

Ollama: http://localhost:11434/v1 — start it with OLLAMA_ORIGINS=chrome-extension://* so the extension may connect. LM Studio: http://localhost:1234/v1 (enable CORS in the server settings). Any OpenAI-compatible server works.

Custom tones

Save your own tone presets — for example “Jermaine Griggs” with the prompt “Rephrase in Jermaine Griggs' voice, in a helpful and polite way”. They appear in the Tone menu in the popup and are also used by the right-click menu and keyboard shortcuts.
